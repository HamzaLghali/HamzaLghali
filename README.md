### About me

I'm a Data Engineer turned AI Engineer based in Morocco, working across banking, real estate and telecoms.
At **Sofrecom (Orange group)** I build large-scale data platforms and generative AI solutions; before that, at **SEVEN** (consulting), I designed data platforms as code and led a client's data team.

My belief: **great AI always starts with solid data.**

- 🔭 Currently building LLM agents with **LangChain, RAG and embeddings**, deployed on **Kubernetes**
- 🌱 Learning more about **MCP, agent evaluation and LLM fine-tuning**
- 💬 Ask me about **Spark, lakehouse architectures, cloud migrations and LLM agents**
- ✍️ I write about my journey on [Medium](https://medium.com/@hamza.lghali.ma/from-data-engineer-to-ai-engineer-463c54a3580a)

### What I've built

| Project | What it does | Stack |
|---|---|---|
| **GitLab CI log analysis agent** | LLM agent that analyzes failed CI jobs and writes structured, prioritized reports: root cause, evidence, fix, severity | LangChain · RAG · FastAPI · Streamlit · Kubernetes |
| **200+ TB telecom data migration** | Moved a year of telecom history from JSON on S3 to Parquet and ClickHouse | PySpark · Rust · ClickHouse · Kubernetes |
| **Lakehouse migration** | Replaced a legacy PostgreSQL data warehouse with a lakehouse, cutting costs | S3 · Iceberg · Spark · Trino |

| **Churn prediction MLOps** | End-to-end churn model with tracking, serving and drift monitoring | MLflow · KServe · Kubeflow · Evidently AI · GCP |
